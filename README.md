# FlashCard Learning Application

A Python-based desktop flashcard application built using Tkinter to help users practice basic Python programming concepts through interactive questions.

## Features

- **Interactive Flashcards:** Click a card to switch between its question and answer.
- **Randomized Questions:** Shuffles the flashcards at the start of each session.
- **Progress Tracking:** Allows users to mark their answers as correct or incorrect.
- **Score Calculation:** Displays the final score after completing all 10 questions.
- **Graphical Interface:** Simple desktop interface built using Python Tkinter.

## Technologies Used

- Python
- Tkinter
- Random module

## How to Run

1. Install Python 3 with Tkinter support.
2. Clone the repository or download the Python file.
3. Open a terminal in the project directory.
4. Run:

   `python flashcard_app.py`

## How It Works

The application presents Python programming questions one at a time. Users can click each flashcard to reveal its answer, then select **Correct** or **Wrong** to record their result and move to the next question.

After all questions are completed, the application displays the final score.

## Project Purpose

This project demonstrates Python programming fundamentals, event-driven GUI development, randomized question selection, and simple application state management.
